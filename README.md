# obsidian-lattice

Lattice 是個人用的 Obsidian theme，以繁體中文為主、含混排文字（英文、簡體中文、日文）的筆記為對象。設計規格見 [Lattice theme 規格（第一輪）](https://github.com/yurenju/obsidian-lattice/issues/17)。

theme 本體在 `sample-vault/.obsidian/themes/Lattice/`（`manifest.json` 與 `theme.css`）。用 Obsidian 開啟 `sample-vault/` 就會套用；需要自行安裝的字型見 [`sample-vault/README.md`](sample-vault/README.md)。
